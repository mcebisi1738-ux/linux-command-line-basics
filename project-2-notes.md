# Project 2: Version Control with Git

## Goal
Manage project files using Git and GitHub.

## Completed practice
- Cloned an existing GitHub repository into WSL.
- Configured my commit author name and email.
- Created and staged a Git workflow guide.
- Reviewed staged changes before committing.
- Created a commit with a descriptive message.
- Authenticated using GitHub CLI.
- Pushed the commit to GitHub.
- Created a documentation branch.

## Lessons learned
- Git records local history; GitHub hosts the shared repository.
- A commit saves staged changes locally.
- A push uploads commits to a remote repository.
- A clean working tree means there are no uncommitted changes.
- Branches let me work separately from main.
- GitHub account passwords cannot authenticate HTTPS Git pushes.
